Rendering the 0% APR badge yourself
Self-rendered — you own the markup
Sam's Club builds the As-Low-As copy server-side from the APR Calculator JAR and renders it in its own storefront, without loading Affirm's affirm.js messaging script. So you render the badge in your own HTML. Everything you need is below — this is exactly what this demo uses.
1 · Markup — put the badge span at the front of the ALA line:
<!-- "0% APR or as low as $88/mo with Affirm. See if you qualify" -->
<span class="apr-badge">0% APR</span> or as low as <b>$88</b>/mo with <Affirm logo>.
2 · CSS — the exact styles Affirm ships (from .__apr_badge.__apr_badge_indigo):
/* indigo "0% APR" badge — Affirm brand tokens */
.apr-badge {
  display: inline-flex; align-items: center; gap: .25em;
  height: 1.5em; padding: .125em .5em; border-radius: .5em;
  font-weight: 500; vertical-align: -0.12em;
  background: #e2e2ff;  /* --bg-surface-brand-indigo */
  color: #4242cf;       /* --text-brand-indigo-oncolor */
}
.apr-badge::before {
  content: ""; width: 1em; height: 1em;
  background: no-repeat center/contain
    url("https://cdn-assets.affirm.com/upfunnel/assets/zero_percent_badge_icon_indigo.svg");
}
3 · Icon — load from Affirm's CDN (above), or inline the SVG to avoid any external request (this demo inlines it as a data: URI). Assets: zero_percent_badge_icon_indigo.svg (indigo) · zero_percent_badge_icon_black.svg (neutral, for light backgrounds).
Only relevant if you later adopt Affirm's script: loading affirm.js + an <p class="affirm-as-low-as"> element makes Affirm render this badge and copy automatically. Docs: Set Up Promotional Messaging · HTML Reference.
If Affirm's page doesn't display inline, open it in a new tab ↗. (Affirm may block embedding.)
